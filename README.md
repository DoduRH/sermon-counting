# Sermon Counting Dashboard

Interactive visualization dashboard for sermon statistics.

## Usage

After generating graphs with the main application, open `output/index.html` in a web browser to view an interactive dashboard with:

- **Category Selection**: Switch between Combined, Emmanuel Bristol, Emmanuel City Church, and Emmanuel Wales
- **Graph Type Selection**: View Bar Charts, Count, Line Charts, or Stacked Bar Charts
- **Quick Navigation Buttons**: Jump directly to specific category/graph combinations
- **Keyboard Shortcuts**: Use arrow keys (← →) to navigate between graph types

## Features

- 🎨 Clean, modern UI with gradient design
- 📊 Interactive graph selection
- 🔄 Real-time switching between visualizations
- 📱 Responsive design (mobile-friendly)
- ⌨️ Keyboard shortcuts for quick navigation
- 🚀 GitHub Pages compatible

## Deployment to GitHub Pages

To deploy the dashboard to GitHub Pages:

```bash
npx gh-pages -d output
```

This will push the `output` directory (including the HTML files and the new index.html) to the `gh-pages` branch, making your dashboard accessible at `https://your-username.github.io/sermon-counting`
